# Centro Odontológico Castellanos

Sitio web oficial del **Centro Odontológico Castellanos**, clínica dental y medicina estética en pleno centro de Avilés (Asturias).

## Tecnologías

- **Framework**: [Next.js](https://nextjs.org/) (App Router)
- **Lenguaje**: TypeScript
- **Estilos**: Tailwind CSS
- **Iconos**: [Lucide React](https://lucide.dev/)
- **Imágenes**: Formato WebP optimizado (85%)

## Desarrollo local

```bash
npm install
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador para ver el resultado.

## Despliegue en Vercel

Este proyecto está optimizado para su despliegue inmediato con cero configuración en [Vercel](https://vercel.com):

1. Accede a tu panel en Vercel.
2. Haz clic en **Add New...** > **Project**.
3. Importa el repositorio `victooorltt/odontologiaCastellanos`.
4. Pulsa **Deploy**.
